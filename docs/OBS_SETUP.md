# OBS Studio Setup Guide for LANCam

This guide explains how to add LANCam video feeds into **OBS Studio** with minimum latency and optimal visual quality.

---

## 1. Prerequisites

- **OBS Studio v27.0+** (v29+ recommended).
- **LANCam Server** running on your local network (e.g., `https://192.168.1.100:3478`).
- Smartphone connected to the **same Wi-Fi network**.

---

## 2. Step-by-Step OBS Configuration

### Step 1: Obtain the Viewer URL
1. Open the LANCam Dashboard in your desktop browser (`https://<SERVER-IP>:3478/dashboard`).
2. Create or open a Session.
3. Connect your smartphone camera by scanning the QR code or visiting the join link.
4. On the Dashboard, click **Copy OBS URL** for the desired camera.
   - Example URL: `https://192.168.1.100:3478/viewer?session=<TOKEN>&camera=CAM-12345`

### Step 2: Add Browser Source in OBS
1. Open **OBS Studio**.
2. Under **Sources**, click the **`+`** icon and select **Browser**.
3. Name the source (e.g., `LANCam - Phone 1`).
4. Set the following properties:
   - **URL**: Paste the copied LANCam Viewer URL.
   - **Width**: `1920` (or `1280` depending on your canvas resolution).
   - **Height**: `1080` (or `720`).
   - **FPS**: `30` (or `60`).
   - **Custom CSS**: Delete default CSS or leave blank (`body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; }`).
   - **Shutdown source when not visible**: Unchecked (recommended so connection stays active when switching scenes).
   - **Refresh browser when scene becomes active**: Unchecked.
5. Click **OK**.

---

## 3. SSL Certificate Trust for OBS

If using self-signed HTTPS certificates generated by LANCam:

### Option A: Trust Root CA System-Wide (Recommended)
Run `mkcert -install` on the machine running OBS. This automatically adds the local CA to system and browser trust stores.

### Option B: Command Line Flag for OBS
Launch OBS with the flag to ignore local SSL errors:
```bash
obs --enable-media-stream --ignore-certificate-errors
```

---

## 4. Latency & Performance Tips

- **Wi-Fi Bandwidth**: Ensure smartphone is connected to a 5 GHz Wi-Fi channel.
- **Video Preset**: Use **720p (BALANCED)** for rock-solid stability, or **1080p (HIGH)** for maximum crispness.
- **Hardware Acceleration**: Enable "Use hardware acceleration when available" in OBS Advanced Settings for Browser Sources.
